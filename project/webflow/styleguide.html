C17

Accessibility · must-pass

WCAG 2.2 AA
  • <html lang="en-NZ"> set in Site Settings.
  • One <h1> per page. Use heading-style_h2 to demote visually without changing the tag.
  • Heading hierarchy never skips a level.
  • Skip link is the first focusable element (try it: Tab from page load).
  • <main> wraps the page body. <nav> wraps the navbar. <footer> wraps the footer.
  • Every meaningful <img> has descriptive alt; decorative images set alt="".
  • Link text is descriptive: Start a conversation, not Click here.
  • Focus rings are visible — 2px red outline, 2px offset (already in CSS).
  • Body contrast: ink on parchment = 16.2:1 · ink on cream = 15.9:1 (above 4.5:1).
  • Red on parchment 5.7:1 · red on cream 5.6:1 (passes for normal text).
  • Tap targets ≥ 44×44px.
  • prefers-reduced-motion respected in CSS.
